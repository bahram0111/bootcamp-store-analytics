# Superstore Data Analysis and Warehousing Project

This project focuses on comprehensive data analysis of the Superstore dataset, covering data warehousing, predictive modeling, customer segmentation, and business insight generation. It was completed as the final project for the Quera Data Analysis Bootcamp.

## Project Objectives & Phases

1. **Data Ingestion & Preprocessing**  
   Loading, cleaning, transforming, and preparing the initial Superstore dataset.

2. **Data Warehousing**  
   Designing and implementing a data warehouse using a star schema, including fact and dimension tables, keys, and relationships. All data warehousing operations were performed using **Power BI**.

3. **Discount Impact Analysis**  
   Investigating whether discounts on products significantly affect the quantity of items sold.

4. **Profit Prediction Model**  
   Developing a generalizable machine learning model to predict product profit using the available features while reducing the risk of overfitting.

5. **Ship Mode Prediction Model**  
   Training a classification model to predict the shipping mode of each order. The results can help businesses encourage customers to choose faster and more profitable shipping services.

6. **Additional Predictive Models**  
   Implementing models for customer segmentation and shipping delay prediction.

7. **Power BI Dashboard**  
   Creating an interactive dashboard to visualize sales performance, profitability, discounts, shipping information, and customer insights.

## Technologies & Tools

* **Python & Machine Learning**: Data preprocessing, feature engineering, exploratory data analysis, customer segmentation, and predictive modeling for profit, ship mode, and delivery delay.
* **Power BI**: Data warehousing, ETL, relationship management, star-schema design, data modeling, and interactive dashboard creation.
